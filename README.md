# AURÉA — Estética & Bem-Estar
Demonstração multipágina da TELARQ Studio. Abra index.html ou sirva a pasta com `python -m http.server 8000`. Para GitHub Pages, envie a pasta 13_estetica intacta para a raiz do repositório e adicione um link `./13_estetica/index.html` na vitrine. Não substitua o index principal. HTML, CSS e JavaScript sem dependências externas. O modo demo não envia mensagens.
