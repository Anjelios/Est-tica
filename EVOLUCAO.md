# Evolução
O front-end é estático. Agendamento real requer API com validação de disponibilidade, autenticação e banco de dados; CMS requer controle de acesso e publicação; analytics exige revisão de privacidade e consentimento quando aplicável. Não exponha segredos no front-end. Separe dados de saúde do site público. As mensagens atuais são preparadas localmente; o usuário controla o envio.
